# Method registry

One row per method ID in `methods.csv`; the xCell2 reference presets are in
`presets.csv`; installed versions and commit SHAs are in `sources.csv`.

The registry is data only: `bulkdeconv` has not been written yet.

| Column | Meaning |
| --- | --- |
| `method` | the ID passed as `method =` |
| `species` | `human`, `mouse`, or both |
| `status` | `ready` (runs with the 4 arguments), `conditional` (needs an extra input, a minimum number of samples, or has a caveat), `unavailable` (cannot run in the current environment), `excluded` (registration required) |
| `expr` | input unit accepted by the method; every method was run with TPM, none with raw counts |
| `min_samples` | measured minimum number of samples |
| `sample_independent` | does a sample get the same value alone as in a cohort (max abs difference measured) |
| `needs` | extra input beyond the four arguments |
| `output_class` | `fraction`, `abundance_score`, `enrichment_score`, `abundance_estimate`, `relative_quantity`, `fraction_modules`; classes must not be compared with each other |
| `n_outputs_measured`, `runtime_s_4_or_6_samples` | measured on the test data |
| `source`, `version`, `pin` | where it is installed from and the exact version (commit SHA for GitHub) |
| `license`, `license_note`, `registration` | licence with its evidence; whether registration is needed |
| `expr_evidence` | what the documentation says about the input unit |

Rule used for inclusion: no registration is required; non-commercial licences are
allowed and reported at run time.

`build_registry.py` regenerates the CSVs from the smoke-test results; the curated
columns (licence, status, notes) are recorded in the script with their evidence.

## Field added later: engine

`engine` is `native` when the method is implemented inside bulkdeconv (R/native*.R,
reference data in inst/extdata; `packages`/`install` then list only a small helper
package such as sva, MASS or quadprog, or nothing) and `external` when the original
package is installed into the private library and run in a separate R process.
Do not edit methods.csv by hand: it is generated by data-raw/build_registry.py.
